# SOUND WALK

曲ごとの「景色」がある3Dマップを歩いて、近づいて、聴いて、買うゲーム。
操作感は Closet Quest と同じ（三人称視点・カメラ基準の移動・ドラッグで視点・クリックで移動・Zで調べる・スマホはスティック＋Aボタン）。

## 遊び方

| 操作 | PC | スマホ | ゲームパッド |
|---|---|---|---|
| 移動 | WASD / 矢印キー（Shiftで走る） | 左下スティック | 左スティック |
| 視点 | ドラッグ / Q・E | ドラッグ | 右スティック |
| そこへ移動 | 地面や光の柱をクリック | タップ | – |
| 眺める・調べる | Z / Enter / Space | Aボタン | A |
| 地図 | M / Esc / MAPボタン | MAPボタン | Start |
| 景色から戻る | Esc / X | もどる | B |

- 広場から5本の道がのび、その先に曲ごとの場所がある。
- **近づくほど音が大きくなる。** 遠くではこもった小さな音で、方向もわかる（左右に定位、HUDの矢印が音の方向を指す）。
- 光の輪の上で **「眺める」** と、カメラがその場所の景色（MVループのような演出）に切り替わる。**眺めている間、音はさらに大きくなっていく**（約12秒で最大）。
- 景色のカードから曲を **購入**（配信ストアへのリンク、または Stripe での直接販売）できる。
- 場所に着くと「発見」になり、地図と光の柱のラベルに曲名が出る（ブラウザに保存）。

### 場所

| 曲 | 場所 | 景色 | 音に連動するもの |
|---|---|---|---|
| KEYAKI | 欅並木 | 金色の午後の並木道。カメラが並木の中をゆっくり進む | 低音で枝が揺れ、高音で葉が多く降り、中音で木漏れ日の光の筋 |
| TAMA EXPRESSION | 夕暮れの河川敷 | 鉄橋を電車が渡る夕景の川 | 対岸のビル群の高さがスペクトラム、川面のきらめきが音量、夕日が低音 |
| FLIP DA HOODS | 裏返しの街 | ネオンの交差点と、頭上に逆さまに吊るされたもう一つの街 | 窓の明かりが帯域ごとに点滅、ネオンがキックで光る、16拍ごとに視界が180°反転 |
| STEREOTYPE | 量産型の広場 | 同じ人形が並ぶモノクロの広場、1体だけピンク | 人形がキックで揃って跳ね、背後のテストパターンがスペクトラム、ピンクが8拍ごとに移動 |
| NO JOBB | 花火の丘 | 夜の丘とベンチ | キックで花火が上がる（強いキックは大玉） |

各場所の雰囲気（空の色・霧・光・彩度）は、近づくにつれて世界全体がその場所の色に変わる。

> 場所の解釈は曲名からの推測です。実際の曲の世界観に合わせて `src/places.js` と `src/songs.js` の文言を調整してください。

## 動かし方

ビルド不要の静的ページです。

```bash
cd SoundWalk
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開く。`index.html` をダブルクリックでも動きますが、実際の音源ファイルを使う場合は上のようにサーバー経由で開いてください（`file://` だとブラウザの制限で音声解析ができず無音になります）。

Vercel / GitHub Pages などにそのまま置けます。three.js r128 は cdnjs から読み込みます。

## 曲の差し替え・追加（`src/songs.js`）

いまは各場所で **仮音源**（その曲のイメージで作ったジェネレーティブな音）が鳴っています。実際の音源にするには:

1. `SoundWalk/audio/` に mp3 などを置く（例 `audio/keyaki.mp3`）
2. `songs.js` の該当曲の `src: null` を `src: 'audio/keyaki.mp3'` に変える

ループ再生され、場所を離れて戻ってきても「ずっと流れていた」ように途中から再生されます。ファイルが読めないときは自動で仮音源に戻ります。別ドメインに置く場合はそのサーバーで CORS（`Access-Control-Allow-Origin`）を許可してください。

曲を増やすときは `SW.SONGS` に1件足すだけです。`scene` に既存の名前（`keyaki` / `tama` / `flip` / `stereotype` / `flash`）以外を入れると、汎用のステージ（円形スペクトラム）が建ちます。位置 `x` / `z` はメートル、広場が原点、±70以内。

## 購入

- **ストアリンク（いまの設定）**: 各曲の `links` に `kind: 'buy'` のURLを入れるとメインボタンになります。KEYAKI / TAMA EXPRESSION / FLIP DA HOODS は LinkCore、STEREOTYPE / NO JOBB は購入先が見つからなかったので SoundCloud の視聴リンクにしています。
- **直接販売（Stripe Checkout）**: `SW.CONFIG.checkoutEndpoint` にエンドポイントを設定し、各曲の `price`（円）を入れると「この曲を買う ¥250」ボタンが出ます。エンドポイントは `{ items: [{ name, price, quantity }] }` を受け取り、`{ url }`（Checkout の URL）を返してください。`{ sessionId }` を返す場合は `stripePublishableKey` も設定します。NS HACK サイトの `/api/stripe/checkout` にそのまま渡せる形式です（同じドメインで配信する場合）。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` | 画面と HUD |
| `src/songs.js` | 曲と場所の設定（編集するのは基本ここだけ） |
| `src/places.js` | 場所ごとの3Dジオラマ・景色のカメラ・音への反応 |
| `src/game.js` | 描画（低解像度レンダリング＋ブルーム）、ワールド、アバター、操作、近接オーディオ、購入 UI |
| `src/audio.js` | 場所ごとのオーディオチャンネル（距離で音量・こもり・定位、解析） |
| `src/synth.js` | 仮音源のシンセとパターン |
