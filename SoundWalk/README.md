# SOUND WALK

曲ごとの「景色」がある3Dマップを歩いて、近づいて、聴いて、買うゲーム。
操作感は Closet Quest と同じ（三人称視点・カメラ基準の移動・ドラッグで視点・クリックで移動・Zで調べる・スマホはスティック＋Aボタン）。

## 遊び方

| 操作 | PC | スマホ | ゲームパッド |
|---|---|---|---|
| 移動 | WASD / 矢印キー | 左下スティック | 左スティック |
| 乗り物で加速 | Shift 長押し | » ボタン（切替） | RT / RB |
| ジャンプ | Space | A（何もない所で） | A |
| 視点 | ドラッグ / Q・E | ドラッグ | 右スティック |
| そこへ移動 | 地面や光の柱をクリック | タップ | – |
| 眺める | Z / Enter | A（光の輪の上で） | A |
| 地図 | M / 右上のミニマップ | ミニマップをタップ | Start |
| 景色から戻る | Esc / X | ← | B |
| 車に乗る・降りる | Z / Enter（車のそば・駐車エリアで） | A | A |
| 運転 | W アクセル / S ブレーキ・バック / A・D ハンドル / Shift 加速 / Space ブレーキ | スティック（上でアクセル）/ » 加速 | 左スティック・RT アクセル・LT ブレーキ・RB 加速 |

画面は文字に頼らない作りです：右上に回転式ミニマップ、画面の端に近い場所への矢印と距離、左上に見つけた曲の数（丸）、操作はキーの絵で表示（動き出すと消える）。
ボードに乗ると速度が上がり、視野が広がってスピード線と風の音が出ます。地図で見つけた場所（色つき）をタップするとワープ、未発見（？）はボードで自動走行します。

- 広場から5本の道がのび、その先に曲ごとの場所がある。
- **近づくほど音が大きくなる。** 遠くではこもった小さな音で、方向もわかる（左右に定位、HUDの矢印が音の方向を指す）。
- 光の輪の上で **「眺める」** と、カメラがその場所の景色（MVループのような演出）に切り替わる。**眺めている間、音はさらに大きくなっていく**（約12秒で最大）。
- 景色のカードから曲を **購入**（配信ストアへのリンク、または Stripe での直接販売）できる。
- 場所に着くと「発見」になり、地図と光の柱のラベルに曲名が出る（ブラウザに保存）。

## 見た目

バイオハザード3・4の頃のサバイバルホラーを意識した、くすんだ色の世界です。曇天と濃い霧、枯れた針葉樹、石畳の広場と井戸の上の焚き火、鉄のランタン、漂う灰。カメラは肩越しで、フィルムグレインと強めの周辺減光がかかります。UI は暗いパネルに細い罫線、タイプライター体、赤の差し色です。色や明るさは `src/game.js` の `BASE`（広場まわり）と、各場所の `p.grade`（`src/places.js` / `src/places2.js`）で調整できます。

マップ上にも全体地図にも文字は出しません。場所は色と形、未発見は「?」、発見済みは「♪」で示します。

OHH の丘の岩・海の岩・峡谷の壁は、形を崩した丸い岩に Poly Haven の岩の写真（`tex/rock_*.jpg`）を貼ったものです。

OHH の丘は北へ、そして北東の遊園地の方へ、丘の連なりとして続きます。環状線の外側（OHH の北、地図の端まで）に高さ10m前後の尾根。環状線の内側は、OHH の丘から遊園地まで切れ目なく山が続き、そのまんなかに **けやき山**（山頂 約17m、KEYAKI の展望台）がそびえます（以前の欅並木のために丘を開けていたところも、いまは山です）。けやき山から東へ尾根が下り、SHOT への道の谷をはさんで、遊園地を囲む **火口壁**（黒っぽい岩の崖。西側がいちばん高く約19m）へ続きます。火口壁は `src/places.js` の遊園地の `p.relief` が丘と同じ高さの格子（`src/game.js`）に描くもので、丘とちがって高架の道路から下がらず、道路の下では床版の4.5m下まで（そこから外へ1mごとに1.6m高く）に抑えられます。だから C1 は南の火口壁のすぐ上を、C1 から環状線へのランプは東の火口壁の上を飛び越えていきます。SHOT への道は火口壁の西の足もとを、切り立った岩の谷として抜けます。歩いて登れ、頂上から見渡せます。丘は道（道は切り通しのように丘を抜ける）、環状線とランプ、広場とループの道、ほかの場所のまわりでは平らに下がるので、平地に建つものが埋まることはありません。KEYAKI の山道だけは丘を切らずに、斜面に沿って山を越えていきます。丘の上は木がまばらで草地が見えますが、山道の両側は森です。残った木は斜面の高さに合わせて立っています。地図にも緑の濃淡で描かれます（`src/game.js` の `BLOBS` がなだらかな丘、`PEAKS` がけやき山と遊園地への尾根の位置と高さ）。丘の高さは描かれた三角形の面そのもので計算するので、足もと・山道・道標が面から浮いたり埋まったりせず、急な斜面でも足が地面にめり込みません。丘はクリック（タップ）でその場所へ歩けます。火口壁は外側の斜面から登れて、縁（ふち）からは火口の中を見下ろせます（縁の手前で止まり、中へは落ちません）。

## 乗り物

Shift（スマホは »）で加速すると乗り物に乗ります。乗るたびにランダムで変わります：左右に車輪のある立ち乗りボード（赤・青・白・黒）、車輪のないレトロなホバーボード（3色）、4つのホバーエンジンが付いた黒いボード、金色の筋斗雲。

## 環状線と車

街の外側を一周する高架の環状線（1周 約780m）があります。SHOT の夜の高速と OHH の海沿いの道はその一部で、FIELD のオフィスの上を越え、TAMA EXPRESSION の線路をまたぎます。4車線で中央分離帯があり、OHH の海沿いだけ2車線になります。日本と同じ左側通行で、ほかの車も走っています。

- **乗る場所**: SHOT の展望台（スロープを上がった先）と、OHH の丘の上の待避所に車が1台ずつ停まっています。そばで Z（スマホは A）。地図とミニマップでは青い四角、道路脇には青い「P」の標識が立っています。 どちらも首都高の駒形パーキングエリアのような、本線の脇の細長い駐車帯です。前後に長いテーパー（すりつけ）があって本線からそのまま寄せて入れ、60°の斜め駐車の枠、トイレと自販機（白・赤・青に光る）の小さな建物とベンチ、背の高い照明、止まっている車が数台。自分の車は出口側を向いた枠に停まっています。SHOT はスロープを上がった歩道から、OHH は丘の上からそのまま歩いて入れます。
- **車**: 7台（シルバーのスポーツクーペ、シルバーのワゴン、黒のSUV、紺と赤のセダン、ツートンのGTクーペ、グレーの3ドアSUV）からランダム。降りるたびに、もう一方の駐車エリアの車が入れ替わります。
- **運転**: 前に進むだけでカーブは道なりに曲がり、ハンドルを離すと車線の中央に戻ります。車線変更や追い越しはハンドルで。壁・中央分離帯・ほかの車には当たります（前の車には自動で速度を合わせます）。Shift（»）で最高速が約130km/h から約180km/h に上がります。
- **降りる**: 駐車エリアに入ってゆっくりにすると Z（A）で降りられます。停めた場所に車が残ります。地図から発見済みの場所へワープすると、車は元の場所に戻ります。
- **景色と音**: 乗ると空が夜に変わり、オレンジの街灯と街の灯りの中を走ります（SHOT・OHH・FIELD などの近くではその場所の光になります）。走っている方角にある曲がカーラジオのように聞こえ、街灯はその曲のビートで明るくなります。

- **C1（首都高・都心環状線ふう）**: 環状線の東（SHOT と FLIP のあいだ）から、街の真ん中を高架で抜けて北西（NO JOBB と TAMA のあいだ）へ向かう、東→西の一方通行・2車線の道（約210m）。広場のすぐ南の上を通ります。平面交差はなく、出入りはすべてランプです（首都高と同じ）。
  - 東で入る: どちら回りでも、左車線の外側の縁から左へ分岐します。時計回りのランプは内側へ上り、反時計回りのランプは環状線の外側で坂を上ってから本線の上を越えます。2本のランプは横に並んだままC1に流れ込みます。
  - 北西で出る: C1の左車線は時計回りへ、右車線は反時計回りへ分かれます。どちらも横から坂を下りてきて、本線の左側（外側の縁）から合流します。
  - **上段（西→東）**: 同じルートの真上 7m に、逆向きの C1 がもう1本、2階建ての高架で重なっています（下段をまたぐ門型の橋脚で支えます）。北西のジャンクションで、どちら回りからも左の縁から分かれる長いランプで上段へ上がり、東のジャンクションで、どちら回りへも横から坂を下りて合流します。車線を保って走れば分岐には吸い込まれず、ランプを逆走して入ることもありません。合流・分岐で本線の壁が開いている区間では、ランプへ横に乗り移れます。分岐とランプには他の車は走っていません。

道の形は `src/ring.js`（曲の位置から自動で決まります）、車のモデルは `src/cars.js`、運転の調整は `src/game.js` の `driveUpdate` です。

## 動かし方

ビルド不要の静的ページです。

```bash
cd SoundWalk
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開く。`index.html` をダブルクリックでも動きますが、実際の音源ファイルを使う場合は上のようにサーバー経由で開いてください（`file://` だとブラウザの制限で音声解析ができず無音になります）。

Vercel / GitHub Pages などにそのまま置けます。three.js r128 は cdnjs から読み込みます。

## 曲の差し替え・追加（`src/songs.js`）

いまは各場所で **仮音源**（その曲のイメージで作ったジェネレーティブな音）が鳴っています。実際の音源にするには:

1. `SoundWalk/audio/` に mp3 などを置く（例 `audio/keyaki.mp3`）
   - `audio/` の中身は git に入りません（`.gitignore`）。このリポジトリは公開なので、未発表の音源が誰でもダウンロードできてしまうのを防ぐためです。公開する場所（Vercel など）には別途アップロードしてください。FIELD は `audio/field.mp3` を参照しています。
2. `songs.js` の該当曲の `src: null` を `src: 'audio/keyaki.mp3'` に変える

ループ再生され、場所を離れて戻ってきても「ずっと流れていた」ように途中から再生されます。ファイルが読めないときは自動で仮音源に戻ります。別ドメインに置く場合はそのサーバーで CORS（`Access-Control-Allow-Origin`）を許可してください。

曲を増やすときは `SW.SONGS` に1件足すだけです。`scene` に既存の名前（`keyaki` / `tama` / `flip` / `park` / `parkwheel` / `flash` / `field` / `shot` / `ohh`）以外を入れると、汎用のステージ（円形スペクトラム）が建ちます。位置 `x` / `z` はメートル、広場が原点、±70以内。

## 購入

- **買える場所は2つ**: 広場の縁（噴水の外側、場所への道がいちばん離れているすきま）にあるレコード店「ATR RECORDS」（atr の作品を売る店。名前は `SW.CONFIG.store.name`）の入口で Z（スマホは A）を押すと、全曲のカタログが大きく開きます。ゲーム内スマホの **STORE** アプリにも同じ一覧があります。まだ見つけていない曲も買えます（一覧に「未発見」と出るだけ）。曲に `store: false` を付けると店から外れます。各曲の行に、購入ボタン（`buy` リンク、または直接販売の価格ボタン）と試聴ボタンが並びます。購入先がない曲は SOON です。
- **ストアリンク（いまの設定）**: 各曲の `links` に `kind: 'buy'` のURLを入れるとメインボタンになります。KEYAKI / TAMA EXPRESSION / FLIP DA HOODS は LinkCore、NO JOBB は購入先が見つからなかったので SoundCloud の視聴リンクにしています。
- **直接販売（Stripe Checkout）**: `SW.CONFIG.checkoutEndpoint` にエンドポイントを設定し、各曲の `price`（円）を入れると「この曲を買う ¥250」ボタンが出ます。エンドポイントは `{ items: [{ name, price, quantity }] }` を受け取り、`{ url }`（Checkout の URL）を返してください。`{ sessionId }` を返す場合は `stripePublishableKey` も設定します。NS HACK サイトの `/api/stripe/checkout` にそのまま渡せる形式です（同じドメインで配信する場合）。

## 広場と世界のしかけ

- **水面と航跡**: 川・海・トンネルの水路の水面には、水の法線マップ（three.js の examples にある `waternormals.jpg`、MIT ライセンス。`tex/water_n.jpg`）を2枚ずらして流した細かい波があり、太陽の照り返しと、斜めから見たときの明るさが乗ります。水上の乗り物で走ると、船尾から泡の輪が左右に広がりながら残って、走ったあとに八の字の航跡ができます（速いほど濃く広く）。

- **火口の遊園地（カルデラ）**: 遊園地は古い火山の火口の中にあります。まわりは黒っぽい玄武岩の崖（岩の写真のテクスチャを三方向から投影。崖の足もとと縁には岩のかたまり、ところどころに六角形の柱状節理）。真ん中は深い緑の **火口湖** で、遊園地の床はその水面より0.9m高い岸壁です（鋲打ちの鉄板の岸壁、石の笠石、鉄の手すり）。湖の東岸には鉄の桟橋があり、鋲打ちの船体に銅のたが、丸窓が光る **潜水艇** が係留されています（司令塔に真鍮の手すりと潜望鏡、潜舵、カゴに入ったスクリュー。低音でゆれる）。湖の中の岩の上には、灯室の光がぐるりと回る鉄骨の **灯台クレーン**（腕がゆっくり湖の上を振れ、先に木箱を吊るす）。北の湖には **間欠泉**（いつも湯気が立ち、強いキックで噴き上がる）。崖の足もとの割れ目からも湯気が上がります。北東と西の崖には、ブラケットで留めた鉄の **キャットウォーク**（銅と錆びた鉄のパイプ、ランプ、岸壁からのはしご）、その先に灯りのもれる洞窟、2本のキャットウォークのあいだには北西の角に **吊り橋** が渡されています。崖の足もとにも鉄格子のはまった洞窟が3つ。ジェットコースターの支柱や街灯も鉄の色です。光は湯気でかすんだ琥珀色。
  - **水の上へ**: 東岸の **スロープ**（鉄板の斜路）から湖へ下りると水上ホバーになり、湖を一周できます（岸壁と桟橋の杭が岸へ上がるのを止め、上がれるのはスロープだけ）。
  - **西の洞窟と運河**: 西の崖の、湖の岸のところに洞窟があり、湖から運河が入っていきます。入口は灯りのともった鉄の **水門の枠**（鋲打ちの柱、巻き上げの歯車、巻き上げられた水門、ランプの列）。中は短いアーチの洞で、いまは奥を鉄の扉が閉じています（ここが OHH の山の下のトンネルのもう一つの入口になる予定）。位置は `SW.Caldera`（下）。
  - **入口**: 広場からの道は C1 の高架の下をくぐって切り通しを上り、火口壁のトンネル（鋲打ちの鉄板と鉄のリブ、両側のランプ）を0.9m上って岸壁に出ます。観覧車への道も同じトンネルを通り、メリーゴーラウンドとコーヒーカップのあいだを抜けます。
  - **`SW.Caldera`**（ワールド座標）: `portal`（運河の洞窟の口 `x` / `z`、水面の高さ `waterY` 0.05、トンネルが続く向き `dir`（単位ベクトル、だいたい西北西）と `yaw`、水路の半幅 `halfWidth` 3.4m、天井の高さ `vault`、いまの洞の奥 `end`、奥の扉 `shut` とその当たり判定 `shutBox`）、`lagoon`（湖の中心、水面と岸壁の高さ、`isWater(x, z)`、輪郭 `outline`）、`floorY`（岸壁の高さ 0.9）、`rim(x, z)`（火口の床の縁から外へのメートル）。いまの値は portal ≈ (0.6, -82.4)、dir ≈ (-0.887, -0.461)、end ≈ (-5.2, -85.4)、湖の中心 ≈ (14.8, -73.9)。次のトンネルは `end` の先から、扉（`shut` を消し、`shutBox` の当たり判定を外す）を開けて続けます。洞の奥から数m先で SHOT への道が火口壁の西の足もとを通っているので、運河はそこで道の下をくぐる（道に橋を架ける）ことになります。
- **乗り場と降り場**: 遊園地のどの乗り物（メリーゴーラウンド、観覧車、コーヒーカップ、空中ブランコ、フリーフォール、ゴーカート、ジェットコースター）にも、緑の「のりば ENTRANCE」ゲート（手すりの付いた行列の通路つき、客が並んでいる）と、オレンジの「おりば EXIT」ゲートがあります。乗れる乗り物は、のりばから乗って、おりばで降ります。空中ブランコのまわりは低い柵で囲まれています。
- **ミニゲーム: コーヒーカップ**: 遊園地のコーヒーカップの前で Z（TEACUPS）。台が止まったら1つ目のカップに乗り込み、一人称で回ります。左のメーターを上下するマーカーが緑の帯にある時に SPIN / Z / A を押すと回転が上がり（PERFECT / GOOD）、外すと少し落ちます（MISS）。何もしないとゆっくり落ちる。最高回転数（rpm）をブラウザに保存。
- **ミニゲーム: フリースロー**: FIELD の裏のバスケコートで、どちらかのフリースローラインに立って Z（スマホは A）。左のメーターを上下するマーカーを緑の帯で止めると（Z / SHOOT）シュート。帯の真ん中ならスウィッシュ、端ならリングに当たって入り、低すぎると手前のリング、高すぎるとボードに当たって外れます。曲の拍に合わせて打つと帯が少し広くなります。連続成功（STREAK）の最高記録をブラウザに保存します。Esc / ✕ で終了。
- **ミニゲーム: ビリヤード**: 広場の縁のビリヤード場（POOL · BILLIARDS）の入口で Z。画面は切り替わらず、カメラが小屋の中の台の手球の後ろに下りて、その場の3Dの台で打ちます。ドラッグ（または ←→、スティック）で狙い、SHOT / Z / Space / A ボタンを押したまま力をためて離すと打ちます。球が転がる間はカメラが台の上に引きます。15個をできるだけ少ない打数で全部落とし（手球を落とすと1打追加）、最少打数をブラウザに保存。球の配置は台に残るので、途中でやめても続きから打てます。Esc / ✕ で終了（物理は `src/pool.js`）。

- **案内板**: 広場の井戸の横。エリア全体の地図（文字なし）で、調べると全体地図が開きます。
- **スマホ**: P か Tab（または右上のボタン）で取り出すゲーム内スマホ。MAP（全体地図）、MUSIC（見つけた曲の一覧。購入・試聴リンクと、その場所へワープする GO）、STORE（全曲の購入ページ）、LIVE（次のライブ）、SHOP（`SW.CONFIG.shop` のリンク）。
- **プレイヤー**: 黒系のテックウェア。艶のあるシェル、マットなパンツ、白いスニーカーに、ハイカラー・チェストハーネス・ラップアラウンドのバイザー。袖と脚のパイピング、靴底、ヘッドホンのリングだけがシアンに光ります（光は線で控えめに）。
- **ライブ会場の観客**: 服・肌・髪がそれぞれ違う18人。グラファイト・黒・オリーブ・アイスグレーのテックシェルで、半分ほどにシアンのパイピング、3人に1人ほどがバイザー。片手を突き上げる、両手を上げる、スマホで撮る、体を揺らす、の4種類の動きで、音が大きいほど大きく動き、強いキックで跳ねます。
- **山道（KEYAKI）**: 欅並木はなくなり、広場から北西のけやき山へ登る山道になりました。踏み固められた土の道が斜面に沿ってうねり（尾根の支脈を登り、肩で一息、山腹を横切って鞍部へ、つづら折りで山頂へ）、急なところは丸太の階段（段ごとに丸太が並び、両端を杭で留めてある）、片側が落ち込むところはロープの手すり、登り口・肩・つづら折りの角に道標（けやき展望台 ▶ / ◀ 広場）。肩には丸太のベンチの休憩所、道ばたには岩、斜面には森と若いけやき。山頂には木の展望デッキ（三方の手すり、海を向いたベンチ2つ、後ろから上がる階段）と「けやき山 展望台」の標柱、デッキの角には古い大きなけやきが立ち、葉が舞い落ち、木漏れ日の光の筋が差します。デッキの上の光の輪で「眺める」と、手すりの前から西の丘と OHH の浜、その向こうの海を見渡します（ほかの場所の「眺める」と違い、展望台なのでまわりの場所も消さずに映します。`p.lookout`）。道筋は `src/places.js` の `PLACES.keyaki` の `TW`（丘と同じワールド座標）で、道具はすべて丘ができてから（`p.afterHills`）地面の高さ（`groundAt`）に置かれます。
- **小道**: 踏み固められた土の小道が、広場から各場所まで続いています。広場のまわりには半径約30mの環状の小道があり、各場所への道を横につないでいます（広場に戻らずに隣の場所へ歩けます）。
- **光のつながり**: 各場所の空や光は、約115m手前から少しずつ混ざり始め、近づくと完全にその場所の色になります。昼の森から夜の街へ、線を越えた瞬間に切り替わることはありません。
- **ライブハウスと駅**: TAMA EXPRESSION の隣のレンガの建物。1階は入口の開いたライブハウスで、中にステージ・照明・観客がいます。ステージ前で調べると次のライブ情報が出ます（`src/songs.js` の `SW.CONFIG.live`、今は `12.26 / TOKYO`）。外階段を上がった2階は終点の駅のホームで、電車が橋を渡ってきて停まります。ドアが開いている間にホームで調べると「このサイトに移動しますか？」と出て、別サイトを新しいタブで開きます（行き先は `SW.CONFIG.shop` の `name` と `url`。`url: null` で無効）。
- **ブラウンストーン**: FIELD の手前に、NYアップタウン風の階段付きの家並み。2人のパフォーマー（赤い上着 = stvn、白い上着 = vas）が曲の再生位置に合わせて動きます。いまのパートを歌っている人がリードで、もう一人は控えめに合わせます。前半は階段の上、1:01 から順にドアを入って後半は2階の窓、曲の終わりに戻ります。それぞれ、相手が歌っている間にだけ移動します。パートの秒数は `src/songs.js` の FIELD の `parts`（今は 0:00 stvn / 0:40 vas / 1:07 stvn / 1:35 vas）。FIELD の曲はこの家並みの前（2人の正面の歩道）で鳴り、光の輪と小道もここに来ます（`src/places2.js` の `p.vp`）。奥のオフィスは保留中で、「眺める」は2人だけを映します（銃撃戦のカットは `CUTAWAYS` を戻すと復活します）。
- **三角のビル**: FIELD の通りと FLIP の街区が斜めに出会うすき間に、フラットアイアン風の三角形の建物（先端が細く面取りされた石造り、またはレンガ）が建つ。
- **デリ**: ブラウンストーンの並びの角に、ニューヨークのデリ（DELI & GROCERY）。明るい店内に棚、緑の日よけ、看板、ちらつくネオンの OPEN、店先に花のバケツと果物の箱。
- **ハーレムの通り**: FIELD の家並み（レンガは写真のテクスチャ。向かいの家並みの裏側にも窓、勝手口、非常階段があります）は、ハーレムの一方通行の住宅街の通りになっています。向かい側にも同じ階段付きの家並みが、こちら向きに並び（家と家が通りをはさんで向き合う）、そのあいだに縁石つきの歩道と車道。歩道には木の植え込みと街路樹、両側の縁石に沿って路上駐車の車、消火栓、ゴミ箱、青いポスト、コブラ型の街灯。向かいの1階には床屋（回る看板ポール）とコインランドリー。階段に座って話す人、歩道で立ち話をする人、犬の散歩、車道でボール遊びをする子どもたち。FLIP 側のビルはこの通りと向かいの家並みの上には建たず、その先の街区になります。
- **TAMA の対岸の港町**: 川の向こう岸は小さな港町です。石の岸壁にボラード（係船柱）と街灯、係留された漁船（低音で揺れる）、レンガの倉庫、赤いクレーン、川が海へ向かう先に白い灯台、窓の明かりが中音で明るくなる家並み。コンテナは岸壁の東の端に一山。町の真ん中は岸壁から奥までまっすぐ抜ける広場で、時計の柱、ベンチ、木が並び、通りがそのまま水辺に出ます。
  町は実際の港町のような並びです。倉庫の裏を岸壁と平行に**港通り（商店街）**が走り、南側は1階が店の2〜3階建て（明かりの灯ったガラス戸、色とりどりの日よけ、魚屋 丸八・喫茶 みなと・食堂 かもめ などの看板）。その裏は幅3mの路地をはさんで背中合わせの家並み、さらに**裏通り**（歩道のない白線だけの住宅街の道）の向こうにもう一列。家にはベランダと洗濯物、エアコンの室外機、玄関のドア、屋根は切妻の瓦か、給水タンクの載った陸屋根。横道が2本（商店街との角に横断歩道）。線路の土手は商店街と裏通りのところだけ鉄の桁の橋になって、その下を道がくぐります（土手には当たり判定あり）。電柱と電線、街灯、自販機、自転車、植木鉢が並び、商店街を人が行き来します。
  町は東へ砂浜まで続きます。商店街を抜けると環状線の高架の下が橋脚のあいだの駐車場（白線の区画と停まった車）で、その先は砂浜の上の**海沿いの遊歩道**（手すりと街灯）。遊歩道には海を向いて海の家 なぎさ、SURF SHOP、カフェ 波音、民宿 しおかぜ などが木のデッキと日よけを出して並び、ここも人が歩いています。建物にはすべて当たり判定があり、高架の下の建物は高架にぶつからない高さです。高架の橋脚は家の上には立てず、そこだけ飛ばしています。
- **漁港（OHH の海側）**: 川がトンネルを抜けて海に出る河口を、2本の石積みの防波堤が囲む漁港です。防波堤の先には赤と白の灯台、浜沿いには河口をはさんで岸壁と木の歩道橋、係留された漁船、屋根だけの魚市場（魚市場の看板、氷の上の魚、木箱）、網干し場。水上の乗り物で川からトンネルを抜けて、そのまま港の中へ入り、防波堤の口から外海へ出られます。
- **砂浜**: 漁港の両側は奥行き30mほどの広い砂浜です。ストライプのパラソルの下のチェアで寝そべる人、クーラーボックスとタオル、ビーチバレー（ネットとロープのコート、4人のあいだをボールが行き来する）、鉄棒で懸垂する人と平行棒、赤い監視台。砂浜・岸壁・河口の歩道橋は歩ける足場になっていて、水上の乗り物になるのは海や川に入ったときだけです。
- **バスケコート（プロジェクト）**: ブラウンストーンの裏、環状線の高架の下に沿って、ニューヨークの団地（プロジェクト）のバスケコート。緑の面にレンガ色のキー、鉄の扇形ボードとチェーンのネット、まわりは金網。向こう側にはレンガの団地が2棟（13階と12階、屋上に給水タンク）。棟の前は一段高い歩道で、そこからコートへ広いコンクリートの階段が下りていて観客席になります。手前の端はブラウンストーンの裏側（非常階段付き）。入口は、FIELD の通りから家並みとオフィスのあいだの路地を抜けた先の金網の門です。
- **川のトンネル**: TAMA EXPRESSION の川は OHH の丘の下のトンネルを抜けて、浜を横切り外周の海へ流れ込みます。両端は石の坑口で、中には灯りがあり、水上ホバーでそのまま通り抜けられます（丘は川に沿って切り通しになっています）。
- **水上ホバー**: 川や海、遊園地の火口湖の上に入ると、自動で水上用の乗り物に乗り換えます（陸に上がると降ります）。海の上では地図の外周より先（約330m）まで出られます。
