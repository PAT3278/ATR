# SOUND WALK

曲ごとの「景色」がある3Dマップを歩いて、近づいて、聴いて、買うゲーム。
操作感は Closet Quest と同じ（三人称視点・カメラ基準の移動・ドラッグで視点・クリックで移動・Zで調べる・スマホはスティック＋Aボタン）。

## 遊び方

| 操作 | PC | スマホ | ゲームパッド |

| 移動 | WASD / 矢印キー | 左下スティック | 左スティック |
| 乗り物で加速 | Shift 長押し | » ボタン（切替） | RT / RB |
| ジャンプ | Space | A（何もない所で） | A |
| 視点 | ドラッグ / Q・E | ドラッグ | 右スティック |
| そこへ移動 | 地面や光の柱をクリック | タップ | – |
| 乗り物に乗る | Z / Enter（乗り場の光の輪で） | A | A |
| 地図 | M / 右上のミニマップ | ミニマップをタップ | Start |
| 乗り物から降りる | Esc / X | ← | B |
| 車に乗る・降りる | Z / Enter（車のそば・駐車エリアで） | A | A |
| 運転 | W アクセル / S ブレーキ・バック / A・D ハンドル / Shift 加速 / Space ブレーキ | スティック（上でアクセル）/ » 加速 | 左スティック・RT アクセル・LT ブレーキ・RB 加速 |
| ラジオ（車・乗り物） | R で局の一覧（↑↓で選び Z / Enter）・画面の ◀ ▶ で局送り | 画面のラジオをタップ・◀ ▶ | 十字キー ← → |
| 曲を買う | 光の輪の上でカードのボタン / B → スマホの曲のページで大きなボタン | カードのボタン → 大きなボタン | X → A |

歩いているあいだ、カメラは進む向きに合わせて少し遅れて背中側へ回り込みます（速いほど速く。画面の奥へ歩くときも横へ歩くときもしっかり追い、手前へ歩くときは回らない）。ドラッグなどで視点を動かすと、その後1秒ほどは追従を止めて手で合わせた向きを保ちます。

画面は文字に頼らない作りです：右上に回転式ミニマップ、画面の端に近い場所への矢印と距離、左上に見つけた曲の数（丸）、操作はキーの絵で表示（動き出すと消える）。
ボードに乗ると速度が上がり、視野が広がってスピード線と風の音が出ます。地図で見つけた場所（色つき）をタップするとワープ、未発見（？）はボードで自動走行します。

- 広場から5本の道がのび、その先に曲ごとの場所がある。
- **近づくほど音が大きくなる。** 遠くではこもった小さな音で、方向もわかる（左右に定位、HUDの矢印が音の方向を指す）。
- 光の輪の上に立ち止まっていると、音はさらに大きくなっていく（約12秒で最大）。以前の「眺める」（カメラが景色の演出に切り替わる機能）は廃止しました。
- **ラジオ**: 車と遊園地の乗り物にはラジオがあり、左下（スマホは上）のラジオ画面で曲を選べる。`AUTO` は以前どおり、車なら近くを走っている場所の曲、乗り物ならその乗り物の曲を受信する。見つけた曲はそれぞれ1つの局（FM 76.4〜）になり、選ぶとその曲だけが流れて周りの音は小さくなる（買っていない曲は試聴、買った曲はフル）。曲が終わると、音源のある次の発見済みの曲へ進む。未発見の局は「？」で選べない。音源のない曲は NO SIGNAL。選んだ局は降りても覚えていて、次に乗ったときにまた流れる。
- 曲の **購入**（配信ストアへのリンク、または Stripe での直接販売）は、光の輪の上に立つと出る曲のカード（ボタン・B キー・パッドの X で、スマホに曲のページが開く）、広場のレコード店のカウンター、スマホの STORE からできる。未発表の曲は **試聴**（ランダムな位置から約20秒ずつ）で、買うとその端末ではフルで聴ける（下の「購入・試聴・再生回数」）。
- **購入画面（曲のページ）**: スマホを出すと、カメラが自分の右肩越しまで寄り（スマホの画面を見ている人を映すように、自分は画面の左、スマホは右）、後ろの景色はぼけて暗くなります。曲のページは、だれでも一目でわかるように、ジャケット・曲名・アーティスト・場所、▶ の試聴プレーヤー、そして大きなボタン1つ（「¥200 で買う」「ストアで買う ↗」「購入済み」「準備中」）と、押すとどうなるかの一行の説明だけ。光の輪から開いたときは「‹ もどる」で歩く画面に戻ります。
- 場所に着くと「発見」になり、地図と光の柱のラベルに曲名が出る（ブラウザに保存）。

## 見た目

バイオハザード3・4の頃のサバイバルホラーを意識した、くすんだ色の世界です。曇天と濃い霧、枯れた針葉樹、石畳の広場と井戸の上の焚き火、鉄のランタン、漂う灰。カメラは肩越しで、フィルムグレインと強めの周辺減光がかかります。UI は暗いパネルに細い罫線、タイプライター体、赤の差し色です。色や明るさは `src/game.js` の `BASE`（広場まわり）と、各場所の `p.grade`（`src/places.js` / `src/places2.js`）で調整できます。

マップ上にも全体地図にも文字は出しません。場所は色と形、未発見は「?」、発見済みは「♪」で示します。全体地図に描かれていない外側（陸の端より外の砂浜など）にいるときは、自分の矢印が地図の縁に白抜きで出ます。

OHH の丘の岩・海の岩・峡谷の壁は、形を崩した丸い岩に Poly Haven の岩の写真（`tex/rock_*.jpg`）を貼ったものです。

OHH の丘は北へ、そして北東の遊園地の方へ、丘の連なりとして続きます。けやき山からは北西へ山並みが続き、環状線の下（道路の下では床版より低く、高架がそのまま山の鞍部を越える）をくぐって、北西の砂浜のすぐ裏で約25〜30mの高さまで上がります（`src/game.js` の `COAST`。けやき山の展望台から海を見る方向だけは低く保つので、眺めはさえぎられません）。丘は砂浜の奥で下がりきり、砂浜・漁港・海にはかかりません。環状線の内側は、OHH の丘から遊園地まで切れ目なく山が続き、そのまんなかに **けやき山**（山頂 約17m、KEYAKI の展望台）がそびえます（以前の欅並木のために丘を開けていたところも、いまは山です）。けやき山から東へ尾根が下り、SHOT への道の谷をはさんで、遊園地を囲む **火口壁**（黒っぽい岩の崖。西側がいちばん高く約19m）へ続きます。火口壁は `src/places.js` の遊園地の `p.relief` が丘と同じ高さの格子（`src/game.js`）に描くもので、丘とちがって高架の道路から下がらず、道路の下では床版の4.5m下まで（そこから外へ1mごとに1.6m高く）に抑えられます。だから C1 は南の火口壁のすぐ上を、C1 から環状線へのランプは東の火口壁の上を飛び越えていきます。SHOT への道は火口壁の西の足もとを、切り立った岩の谷として抜けます。歩いて登れ、頂上から見渡せます。丘は道（道は切り通しのように丘を抜ける）、環状線とランプ、広場とループの道、ほかの場所のまわりでは平らに下がるので、平地に建つものが埋まることはありません。KEYAKI の山道だけは丘を切らずに、斜面に沿って山を越えていきます。丘の上は木がまばらで草地が見えますが、山道の両側は森です。残った木は斜面の高さに合わせて立っています。開けた斜面には低い灌木と小石が点々とあり（約900、色3種の灌木と石で4回の描画）、金色の光の中でも砂丘には見えません。灌木は低いので、木を立てない KEYAKI の眺めの中や OHH の海側の丘にも生えます（場所が `p.scrubOut` を持てばそれで、なければ `p.blocks` で除外）。地図にも緑の濃淡で描かれます（`src/game.js` の `BLOBS` がなだらかな丘、`PEAKS` がけやき山と遊園地への尾根の位置と高さ。最後の3つは、下を通る OHH の用水路（下の「OHH の古い用水路」）がどこでも埋まっているように足した、けやき山の西の鞍部・OHH の北の小山・SHOT への道のそばのけやき山の裾）。場所が `p.carve` を持つと、丘も火口壁の岩もそこで掘り下げられます（用水路の切り通し）。丘の高さは描かれた三角形の面そのもので計算するので、足もと・山道・道標が面から浮いたり埋まったりせず、急な斜面でも足が地面にめり込みません。丘はクリック（タップ）でその場所へ歩けます。火口壁は外側の斜面から登れて、縁（ふち）からは火口の中を見下ろせます（縁の手前で止まり、中へは落ちません）。

森の木は、Poly Haven の木の3Dモデル（CC0）を画像に焼き付けたもの（`tex/trees.png`、7本×正面と横）を板に貼って立てています。若いモミとマツ（Fir Sapling / Pine Sapling Small から6本）は3枚の板を60°ずつ、広葉樹の若木（Tree Small 02）は2枚の板を直角に組み合わせます。約1200本、木の種類ごとに1回の描画で済みます。針葉樹は葉の付き始めを地面から3m前後（木の高さの約1/4）まで持ち上げ、その下は樹皮の幹だけにしているので、森の中でも幹の間から先が見通せます。

広葉樹は、細い幹が途中で二股に分かれ、枝が横へ大きく広がる、針葉樹とはまったく違う枝ぶりの木です。画像にしたのは幹が分かれるところから上の樹冠だけで、その下の、傾きながら曲がって伸びる幹は、モデルの幹の中心線と太さをなぞった立体の幹です。2枚の板はどちらもその分かれ目を通るので、どの向きから見ても枝が幹の先から伸びて見えます。分かれ目で立体の幹と画像の幹がひと続きに見えるよう、立体の幹は画像の幹と同じ灰色の樹皮の色で、木ごとの色合いも板と同じ、上の3分の1は板と同じように光が当たります（広葉樹の板は裏から見ても表と同じに照らされ、幹の上の方は自分自身には影を落としません。地面やまわりには影を落とします）。広葉樹は5本に1本くらいで、ところどころにまとまった林をつくり、丘の上では少なくなります。もとは高さ4.6mの若木なので、大きくしすぎて葉が大きく見えないよう、高さは20m前後までにしています（`src/game.js` の `Trees:`）。

**見た目は Bryce 3D（1994）ふう**: 深い青から地平線の暖かいもやへのグラデーションの空、ハローのある大きな太陽、下側に影のある積雲。丘は高さで塗り分け（低いところはオリーブ、斜面は赤茶と黄土の地層、頂上は雪）、地平線には地層と雪をかぶったフラクタルの山並み。フィルムグレインやセピアはなく、彩度を上げて、4×4 のディザで階調を少し落とした90年代のレンダリング風。広場の噴水の上にはクロームの球。各場所の雰囲気（夜や夕暮れ）はそのまま残しています。

地面・広場のレンガ・アスファルト・舗装・砂は、Poly Haven の写真ベースのテクスチャ（CC0、`tex/` フォルダ。色と法線マップ）です。道路のアスファルト（`tex/asphalt_*.jpg`）は Poly Haven の asphalt_04 で、細かい骨材の粒と補修跡のある実際の車道の舗装です（コントラストを少し上げ、明るさと彩度を落としてあります）。高速道路・FLIP と FIELD の通り・駐車場・トンネル前の道に使っています。差し替えは `tex/<名前>_d.jpg` / `_n.jpg` を置き換えるだけで、`src/game.js` の `PHOTO` から名前を外すと元の描画テクスチャに戻ります。

街の人（通行人、ご近所さん、クラブや遊園地の客、待ち列の人）は、Quaternius の「Ultimate Modular Men / Women」の 8 体（CC0、Poly Pizza 経由、`models/people/`）です。全員が同じ骨組みなので、アニメ（立つ・歩く・走る・座る・拍手・ジャンプなど 11 種類）は男女 1 セットずつだけを持ち、全員で使い回します。部位（肌・髪・上着・中の服・ズボン・靴）ごとに色を塗り替えるので、8 体から何千通りの人ができます。`src/people.js` が読み込んでから `src/game.js` を始めます（読み込めないときは手作りの人形に戻ります）。モデルは `node tools/pack-people.mjs <元のフォルダ> models/people man1=…glb+ man2=…glb …` で詰め直しています（使わない骨のデータを省き、重みと法線を 1 バイトに。8 体で約 1.5 MB）。

## 環状線と車

街の外側を一周する高架の環状線（1周 約780m）があります。SHOT の夜の高速と OHH の海沿いの道はその一部で、FIELD の通りの上を越え、TAMA EXPRESSION の線路をまたぎます。4車線で中央分離帯があり、OHH の海沿いだけ2車線になります。日本と同じ左側通行で、ほかの車も走っています。

- **乗る場所**: SHOT の駐車エリア（スロープと歩道橋を上がった先）、OHH の丘の上の待避所、OHH の東の砂浜の上の海側の待避所（BEACH PA）に車が1台ずつ停まっています。BEACH PA は環状線の海側の待避所で、裏から歩道が砂浜の上に突き出し、その先のエレベーター（鉄骨のかご）が砂浜と待避所のあいだを自動で上り下りしています（下で4秒、上りに5秒、上で4秒、下りに5秒。かごの床に立っていれば運んでくれるので階段はありません）。そばで Z（スマホは A）。地図とミニマップでは青い四角、道路脇には青い「P」の標識が立っています。 どちらも首都高の駒形パーキングエリアのような、本線の脇の細長い駐車帯です。前後に長いテーパー（すりつけ）があって本線からそのまま寄せて入れ、60°の斜め駐車の枠、トイレと自販機（白・赤・青に光る）の小さな建物とベンチ、背の高い照明、止まっている車が数台。自分の車は出口側を向いた枠に停まっています。SHOT はスロープから歩道橋を渡った歩道から、OHH は丘の上からそのまま歩いて入れます。駐車エリアの床（デッキ）は、その上にいる人の足場です。下を歩いていても持ち上げられることはなく、SHOT の駐車エリアの下は柱のあいだを通り抜けられます。デッキの端（テーパーの斜めの縁と側面、建物の前の張り出しと歩道の両側）には手すりがあり、下が一段より低いところで足を踏み外すことはありません。OHH では丘がデッキのすぐ下まで迫って頭がつかえるところは下からは入れず、丘の上の同じ高さから乗ります。
- **車**: 7台（シルバーのスポーツクーペ、シルバーのワゴン、黒のSUV、紺と赤のセダン、ツートンのGTクーペ、グレーの3ドアSUV）からランダム（ホイールはシルバーか黒。街を走る車・停まっている車は約3台に1台が黒ホイール。SEASIDE MOTORS では7台それぞれシルバーと黒の両方を選べ、計14通り）。降りるたびに、もう一方の駐車エリアの車が入れ替わります。BEACH PA の車だけは、砂浜沿いの車屋 SEASIDE MOTORS のカウンターで選べます（Z / A を押すたびに次の車種になり、ショールームのターンテーブルにも同じ車が載ります）。
- **高架下の道**: FLIP の大通りから高架下を北へ曲がった道は、そのまま環状線の高架の下（外側）を通って遊園地の裏（立体駐車場の横）を過ぎ、SHOT の高速の下をくぐり、KEYAKI の北西の丘を切り通しで抜けて、OHH の北の砂浜の裏に下りてきます。砂浜沿いには、ガラス張りのショールームの車屋（SEASIDE MOTORS）、リフトに車が上がった2ベイのガレージ（PIT GARAGE）、のぼりと万国旗の中古車展示場が並び、道の突き当たりの先が BEACH PA のエレベーターです。道と店は `src/street.js` です。
- **南の山と峠道（はなび峠）**: NO JOBB の宮殿の南に大きな山があり、環状線と外側の高架は山の下をトンネルで抜けます。峠道は **車で走れます**。FLIP の大通りから高架下を南へ曲がった道（FIELD の裏で FIELD の通りを渡る）が、そのまま環状線と外側の高架の下をくぐって山の麓へ出て、東の斜面を4本の脚と3つのヘアピンで登り、山頂の東を回って両方のトンネルの上の峠（「はなび峠」の看板とベンチ）を越え、町の側を2つのヘアピンで下って宮殿の裏の柱廊に着きます（全長約480m、峠の高さ24m）。車は麓・峠・宮殿の3か所の待避所に停まっていて、乗り降りやUターンができます。歩いても通れます。山は町の端（|z| 145）の外まで広がっていて、その上も歩けます
- **下道を走る**: PIT GARAGE の東のベイと、遊園地の立体駐車場の1階にも車が停まっています（乗り降りできます）。ガレージから出ると、高架下の道を一方通行で北東へ走り、遊園地の裏で道をそれて、大黒ジャンクションのような2周の螺旋ランプを上り、環状線の外側を上る C1 の入口ランプに外から合流して、そのまま C1 の下段に入れます。立体駐車場は北側の1階が開いていて、環状線の下をくぐる取付道路で螺旋の手前に合流します（駐車場へも入れます）。
- **運転**: 前に進むだけでカーブは道なりに曲がり、ハンドルを離すと車線の中央に戻ります。車線変更や追い越しはハンドルで。壁・中央分離帯・ほかの車には当たります（前の車には自動で速度を合わせます）。Shift（»）で最高速が約130km/h から約180km/h に上がります。
- **降りる**: 駐車エリアに入ってゆっくりにすると Z（A）で降りられます。停めた場所に車が残ります。地図から発見済みの場所へワープすると、車は元の場所に戻ります。
- **景色と音**: 乗ると空が夜に変わり、オレンジの街灯と街の灯りの中を走ります（SHOT・OHH・FIELD などの近くではその場所の光になります）。走っている方角にある曲がカーラジオのように聞こえ、街灯はその曲のビートで明るくなります。

- **C1（首都高・都心環状線ふう）**: 環状線の東（SHOT と FLIP のあいだ）から、街の真ん中を高架で抜けて北西（NO JOBB と TAMA のあいだ）へ向かう、東→西の一方通行・2車線の道（約210m）。広場のすぐ南の上を通ります。平面交差はなく、出入りはすべてランプです（首都高と同じ）。
  - 東で入る: どちら回りでも、左車線の外側の縁から左へ分岐します。時計回りのランプは内側へ上り、反時計回りのランプは環状線の外側で坂を上ってから本線の上を越えます。2本のランプは横に並んだままC1に流れ込みます。
  - 北西で出る: C1の左車線は時計回りへ、右車線は反時計回りへ分かれます。どちらも横から坂を下りてきて、本線の左側（外側の縁）から合流します。
  - **上段（西→東）**: 同じルートの真上 7m に、逆向きの C1 がもう1本、2階建ての高架で重なっています（下段をまたぐ門型の橋脚で支えます）。北西のジャンクションで、どちら回りからも左の縁から分かれる長いランプで上段へ上がり、東のジャンクションで、どちら回りへも横から坂を下りて合流します。車線を保って走れば分岐には吸い込まれず、ランプを逆走して入ることもありません。合流・分岐で本線の壁が開いている区間では、ランプへ横に乗り移れます。C1 は上段・下段とも、入口ランプから入って出口ランプで環状線に戻る車が走っています。内回りから C1 へ入るランプは、走行車線の脇から車線が横に増えるように分かれ、しばらく並走してから離れて上ります。

道の形は `src/ring.js`（曲の位置から自動で決まります）、車のモデルは `src/cars.js`、運転の調整は `src/game.js` の `driveUpdate` です。

## 動かし方

ビルド不要の静的ページです。

```bash
cd SoundWalk
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開く。`index.html` をダブルクリックでも動きますが、実際の音源ファイルを使う場合は上のようにサーバー経由で開いてください（`file://` だとブラウザの制限で音声解析ができず無音になります）。

Python の `http.server` は Range リクエスト（ファイルの途中から読む）に対応していないので、ブラウザは音源の途中へ飛べません。そのときゲームは、試聴の曲（とフル再生の曲を波形で飛ばしたとき）をいったん丸ごと読み込んでメモリから再生します（最初の1回だけ少し待ちます）。`npx serve` など Range に対応したサーバーや、Vercel / GitHub Pages ではそのまま途中から読みます。

Vercel / GitHub Pages などにそのまま置けます。three.js r128 は cdnjs から読み込みます。

## 曲の差し替え・追加（`src/songs.js`）

いまは各場所で **仮音源**（その曲のイメージで作ったジェネレーティブな音）が鳴っています。実際の音源にするには:

1. `SoundWalk/audio/` に mp3 などを置く（例 `audio/keyaki.mp3`）
   - `audio/` の中身は git に入りません（`.gitignore`）。このリポジトリは公開なので、未発表の音源が誰でもダウンロードできてしまうのを防ぐためです。公開する場所（Vercel など）には別途アップロードしてください。FIELD は `audio/field.mp3` を参照しています。
2. `songs.js` の該当曲の `src: null` を `src: 'audio/keyaki.mp3'` に変える
3. 未発表の曲なら `access: 'preview'`（試聴だけ。買うとフル）、公開済みの曲なら `access: 'full'`（無料でフル再生）。書かなければ `SW.CONFIG.access`（今は preview）

ループ再生され、場所を離れて戻ってきても「ずっと流れていた」ように途中から再生されます。ファイルが読めないときは自動で仮音源に戻ります。別ドメインに置く場合はそのサーバーで CORS（`Access-Control-Allow-Origin`）を許可してください。

曲を増やすときは `SW.SONGS` に1件足すだけです（`SW.CONFIG.api` でショップのサーバーにつないでいるときは、nshack の `lib/soundwalk.ts` の `SONGS` にも同じ `id` と価格で足してください。サーバーのカタログにない曲は買えず、再生回数も数えられません）。`scene` に既存の名前（`keyaki` / `tama` / `flip` / `park` / `parkwheel` / `flash` / `field` / `shot` / `ohh`）以外を入れると、汎用のステージ（円形スペクトラム）が建ちます。位置 `x` / `z` はメートル、広場が原点、±70以内。

## 購入・試聴・再生回数

- **買える場所は2つ**: 広場の縁（噴水の外側、場所への道がいちばん離れているすきま）にあるレコード店「ATR RECORDS」（atr の作品を売る店。名前は `SW.CONFIG.store.name`）の入口で Z（スマホは A）を押すと、全曲のカタログが大きく開きます。ゲーム内スマホの **STORE** アプリにも同じ一覧があり、**MUSIC** で曲を選んだ画面にも同じプレーヤーが出ます。まだ見つけていない曲も買えます（一覧に「未発見」と出るだけ）。曲に `store: false` を付けると店から外れます。
- **プレーヤー（SoundCloud ふう）**: 1曲ごとに、再生／一時停止ボタン、波形（再生位置まで曲の色で光る。フル再生の曲は波形をクリックでその位置へ）、時間（試聴は切り出しの中の時間、DEMO はループなので鳴っている時間だけ）、種類のタグ（PREVIEW / FULL / DEMO）、再生回数（▶ 1.2K）、購入ボタン（配信先で聴ける曲はその LISTEN ↗ リンクも）が並びます。波形は一度再生した曲は本物（低いサンプルレートで読み込んで端末に保存）、それまでは仮の形です。プレーヤーが鳴っている間は場所の音が小さくなり、店やスマホを閉じると止まります。
- **試聴とフル再生（曲ごとの `access`）**:
  - `'preview'`: 買っていない間は、曲の **ランダムな位置から `SW.CONFIG.preview` 秒（今は20秒）だけ**、フェードイン・アウトして流れます（フェードはオーディオの時計に予約するので、画面が重くて処理が止まっても切り出しの終わりで確実に消えます）。位置は毎回変わります（前回と近い位置は避ける）。店・スマホのプレーヤーでは1回の再生で1か所、地図上のその場所では少し間をおいて次の位置が流れ続けるので、どこでも曲を通しでは聴けません。プレーヤーの波形では、いま流れている区間が明るくなります。景色のカードには PREVIEW 20s と出ます。
  - `'full'`: SoundCloud のように無料でフル再生（購入ボタンはあります）。
  - 既定は `SW.CONFIG.access`（今は `'preview'`）。いまの設定は、配信中の KEYAKI / TAMA EXPRESSION / FLIP DA HOODS と SoundCloud で公開中の NO JOBB が full、未発表の FIELD / SHOT / OHH と遊園地の2曲が preview。
  - 音源ファイルのない曲（`src: null`）は鳴りません。プレーヤーでは COMING SOON と表示され、再生ボタンは押せません（以前の仮のシンセ音源は `SW.CONFIG.demo: true` にすると戻せます）。
- **直接販売（Stripe Checkout）**: `SW.CONFIG.api` に NS HACK サイトの API（`https://<NS HACK のドメイン>/api/soundwalk`。nshack の `SETUP.md`「SOUND WALK のショップ API」）を入れると、サーバーが答えて支払いを受けられる（Stripe のキーが設定済み）と言ったときだけ、価格ボタン（¥250）が出ます。押すと Stripe の支払いページに移り、支払いが済むとゲームに戻ってきます（同じ場所から再開）。戻り URL には Checkout のセッション ID が付いていて、ゲームはサーバーの `verify` で **支払い済みかを Stripe に確認してから**、その端末で購入済み（OWNED）にします（ブラウザの `soundwalk-owned` に保存）。以後その端末では、試聴の曲もプレーヤーと場所の両方でフルに流れます。確認が通信エラーで失敗したときは、数秒おきにあと2回確認し、それでもだめなら「お支払いを確認しています…」と出して、次に開いたとき（とスマホや店を開いたとき）にもう一度確認します。コンビニ払いなど入金があとになる支払いは「お支払いの完了を待っています」と出て、入金が済んだあとに開いたときに OWNED になります。キャンセルしたときは「購入をキャンセルしました」と出ます。
  - 価格はサーバーのカタログ（nshack の `lib/soundwalk.ts`）が正です。ゲームはサーバーから受け取った価格を表示し、ゲームが送る価格は使われません。`songs.js` の `price` はサーバーにつながるまでの表示用です。
  - サーバーが答えるまで・つながらないとき・Stripe のキーがないとき、それと支払いページを開けなかったあと2分間は、購入ボタンが各曲のストアリンク（なければ SOON）になります。
- **再生回数**: 店・スマホのプレーヤー、車や乗り物のラジオ、乗り物に乗っているときに、本物の音源が6秒聞こえたら1回として送ります（`POST /play`。音を消しているときは数えません）。同じ曲は、30秒以上ほかの曲に移るか止めてからでないと次の1回になりません（サーバー側でも、同じ人・同じ曲は30秒に1回）。
- **`SW.CONFIG.api` が null のとき（いまの設定）**: 再生回数は出ず、購入ボタンは各曲の `links` の `kind: 'buy'`（KEYAKI / TAMA EXPRESSION / FLIP DA HOODS は LinkCore）を開きます。購入先がない曲は SOON です。NO JOBB のように配信先で聴ける曲は、その視聴リンク（LISTEN ↗）を店・STORE の行とスマホの曲の画面に出します。
- **注意**: 試聴の制限はブラウザの中の仕組みなので、mp3 の URL を直接開けば曲全体を取得できます。公開サイトで本当に守るには、試聴用に切り出したファイルや署名付き URL をサーバー側で用意する必要があります（未実装）。購入済みの記録も端末のブラウザに保存されるだけで、ダウンロード用のファイルを渡す仕組みはまだありません。

## 広場と世界のしかけ

- **水面と航跡**: 川・海・トンネルの水路の水面には、水の法線マップ（three.js の examples にある `waternormals.jpg`、MIT ライセンス。`tex/water_n.jpg`）を2枚ずらして流した細かい波があり、太陽の照り返しと、斜めから見たときの明るさが乗ります。水上の乗り物で走ると、船尾から泡の輪が左右に広がりながら残って、走ったあとに八の字の航跡ができます（速いほど濃く広く）。

- **火口の遊園地（カルデラ）**: 遊園地は古い火山の火口の中にあります。まわりは黒っぽい玄武岩の崖（岩の写真のテクスチャを三方向から投影。崖の足もとと縁には岩のかたまり、ところどころに六角形の柱状節理）。真ん中は深い緑の **火口湖** で、遊園地の床はその水面より0.9m高い岸壁です（鋲打ちの鉄板の岸壁、石の笠石、鉄の手すり）。湖の東岸には鉄の桟橋があり、鋲打ちの船体に銅のたが、丸窓が光る **潜水艇** が係留されています（司令塔に真鍮の手すりと潜望鏡、潜舵、カゴに入ったスクリュー。低音でゆれる）。湖の中の岩の上には、灯室の光がぐるりと回る鉄骨の **灯台クレーン**（腕がゆっくり湖の上を振れ、先に木箱を吊るす）。北の湖には **間欠泉**（いつも湯気が立ち、強いキックで噴き上がる）。崖の足もとの割れ目からも湯気が上がります。北東と西の崖には、ブラケットで留めた鉄の **キャットウォーク**（銅と錆びた鉄のパイプ、ランプ、岸壁からのはしご）、その先に灯りのもれる洞窟、2本のキャットウォークのあいだには北西の角に **吊り橋** が渡されています。崖の足もとにも鉄格子のはまった洞窟が3つ。ジェットコースターの支柱や街灯も鉄の色です。光は湯気でかすんだ琥珀色。
- **立体駐車場（遊園地）**: 遊園地の奥の右手、火口壁を切り開いたところに4層の立体駐車場（地上と3つのデッキ。屋上は高さ約9mで、その上を環状線へのランプが高さ17〜19mで越えていく）。南の面から遊園地の床のまま歩いて入れて、西の車線のスロープで2階へ、北の端を渡って東の車線のスロープで3階へ、南の端を渡って西の車線のもう1本のスロープで屋上へ、と階段なしで上がれます。各階に停まった車、デッキの下の蛍光灯、屋上の照明、コンクリートの腰壁と黄色い手すり、南の面の上と入口の脇に「P 立体駐車場 PARKING」の青い看板。各階の床はその高さにいる人にだけ地面になるので、下の階を歩いていて上の階に持ち上げられることはありません。車には乗れない、眺めて歩くための場所です（`src/places.js` の遊園地の `CP`）。
  - **水の上へ**: 東岸の **スロープ**（鉄板の斜路）から湖へ下りると水上ホバーになり、湖を一周できます（岸壁と桟橋の杭が岸へ上がるのを止め、上がれるのはスロープだけ）。
  - **西の洞窟と運河**: 西の崖の、湖の岸のところに洞窟があり、湖から運河が入っていきます。入口は灯りのともった鉄の **水門の枠**（鋲打ちの柱、巻き上げの歯車、巻き上げられた水門、ランプの列）。中は短いアーチの洞で、火口壁を抜けた先は **OHH の古い用水路**（下）の入口です。洞の中では湖の腕が片側に寄り、もう片側（湖から入っていくと左）を用水路の曳舟道が岸壁と同じ高さで通っているので、岸壁からそのまま歩いて入れます。火口壁の外側の口には岩の面に石のアーチと「TO OHH」の札。口の前の岩は用水路に沿って掘り下げてあり、水路をふさぎません。湖の腕は洞の奥の端でまっすぐ終わり、そこから先は用水路の水です。洞の口の両側の岸壁の柱（手すりの下の当たり判定）もそのままなので、上がれるのはやはりスロープだけです。位置は `SW.Caldera`（下）。
  - **入口**: 広場からの道は C1 の高架の下をくぐって切り通しを上り、火口壁のトンネル（鋲打ちの鉄板と鉄のリブ、両側のランプ）を0.9m上って岸壁に出ます。観覧車への道も同じトンネルを通り、メリーゴーラウンドとコーヒーカップのあいだを抜けます。
  - **`SW.Caldera`**（ワールド座標）: `portal`（運河の洞窟の口 `x` / `z`、水面の高さ `waterY` 0.05、トンネルが続く向き `dir`（単位ベクトル、だいたい西北西）と `yaw`、水路の半幅 `halfWidth` 3.4m、天井の高さ `vault`、洞の外の口 `end`）、`lagoon`（湖の中心、水面と岸壁の高さ、`isWater(x, z)`、輪郭 `outline`）、`floorY`（岸壁の高さ 0.9）、`rim(x, z)`（火口の床の縁から外へのメートル）。いまの値は portal ≈ (0.5, -82.4)、dir ≈ (-0.887, -0.461)、end ≈ (-5.2, -85.4)、湖の中心 ≈ (14.8, -73.9)。OHH の用水路は `end` から `dir` の向きにまっすぐ出て、SHOT への道の切り通しを渡ります。
- **乗り場と降り場**: 遊園地のどの乗り物（メリーゴーラウンド、観覧車、コーヒーカップ、空中ブランコ、フリーフォール、ゴーカート、ジェットコースター）にも、のりば（ENTRANCE）とおりば（EXIT）のゲートがあり、ゲートの看板にはその乗り物の名前が乗り物ごとの色で大きく書かれています（例：赤の「メリーゴーラウンド」、青の「観覧車」）。その下の帯が緑ならのりば、オレンジならおりばです。のりばには手すりの付いた行列の通路があって客が並び、横には遠くからでも見える乗り物の名前の看板が柱の上に立っています。乗れる乗り物は、のりばから乗って、おりばで降ります。乗り物どうしは間をあけて配置しています（火口の床は東側に広げてあり、コーヒーカップ・空中ブランコ・フリーフォールは東寄り）。空中ブランコのまわりは低い柵で囲まれています。
- **ジェットコースターと観覧車**: ジェットコースターは遊園地全体を飛ぶように走ります。乗り場（岸壁の南）を出て西の崖を巻き上げで約27mまで上がり、火山の裏へ一気に落ちて宙返り、ゴーカートの上を東へ、観覧車とフリーフォールのあいだを南へ抜け、空中ブランコの上空約22mを越えて、コーヒーカップと風船売りの上から乗り場に戻ります。現実離れした設計で、支える柱は全周で6本ほどしかなく、ほとんど宙に浮いています（湖の上には柱を立てません）。観覧車は前後2枚の大きな A 字の脚（足もとは左右に7mずつ開き、頭上の高さに横木）に載っていて、真ん中が大きく開いているので、ゴンドラが下りてくる乗り場（黄色い縁の台）がゲートからまっすぐ見えます。
- **ミニゲーム: コーヒーカップ**: 遊園地のコーヒーカップの前で Z（TEACUPS）。台が止まったら1つ目のカップに乗り込み、一人称で回ります。左のメーターを上下するマーカーが緑の帯にある時に SPIN / Z / A を押すと回転が上がり（PERFECT / GOOD）、外すと少し落ちます（MISS）。何もしないとゆっくり落ちる。最高回転数（rpm）をブラウザに保存。
- **ミニゲーム: フリースロー**: FIELD の3棟のアパートの中庭のハーフコートで、フリースローラインに立って Z（スマホは A）。左のメーターを上下するマーカーを緑の帯で止めると（Z / SHOOT）シュート。帯の真ん中ならスウィッシュ、端ならリングに当たって入り、低すぎると手前のリング、高すぎるとボードに当たって外れます。曲の拍に合わせて打つと帯が少し広くなります。連続成功（STREAK）の最高記録をブラウザに保存します。Esc / ✕ で終了。
- **ミニゲーム: ビリヤード**: 広場の脇、OHH と TAMA へ向かう道のあいだに建つ天井の高いレンガのビリヤード場（POOL · BILLIARDS。入口から建物の向きのまま広場のふちまで短い小道がまっすぐ延びていて、小道を上ると入口に正面から入れます）の入口で Z。中の台は実物の3倍の大きさで、ラシャ・クッション・レール（ダイヤモンドつき）・ポケット・球（直径約17cm）・キュー（約4.4m）・台の上のランプまですべて3倍、壁には巨大なキューが2本立てかけてあります（足もとには当たり判定あり）。台の高さだけは1.3mに抑えてあるので、台のまわりの通路を歩きながらレール越しに球が見えます（建物の中で壁に押されたカメラは、高めの位置から肩越しに先を見ます。ただし見る先は壁から1m手前までで、隅で壁のほうを向いても壁だけの画面にはなりません。壁ぎわに立ったときも、肩越しのずらしやカメラの位置が壁の中や外に出ることはなく、壁が近ければ頭の上まで寄ります（レコード店の中も同じ）。台の上にはカメラが入れても、台の中には入りません）。画面は切り替わらず、カメラが台の手球の後ろに下りて、その場の3Dの台で打ちます。ドラッグ（または ←→、スティック）で狙い、SHOT / Z / Space / A ボタンを押したまま力をためて離すと打ちます。手球が壁ぎわにあるときは、カメラが壁の内側まで寄って少し上がります。3倍の長いキューは、手球の後ろのクッションとレールの上をちょうど越える角度まで持ち上がり（手球がクッションに近いほど立てて構え、くっついているときは先端がクッションの上に乗ります）、引くときは自分の軸に沿って下がり、後ろの壁が近いときは壁を突き抜けないよう短くなります。キューを立てたときはカメラもその上まで上がります。球が転がる間はカメラが入口側の天井近くから台全体を見下ろします。15個をできるだけ少ない打数で全部落とし（手球を落とすと1打追加）、最少打数をブラウザに保存。球の配置は台に残るので、途中でやめても続きから打てます。全部落とすと、SHOT（または次に台に来たとき）で15個を並べ直します。Esc / ✕ で終了。物理は実寸のまま（`src/pool.js`、メートル）で、描画・狙い線・キューの引き・カメラの位置だけを3倍にしています（倍率・台の高さ・建物の大きさは `src/game.js` の `HALL`）。建物の場所は決め打ちではなく、広場のまわりで道・ループ・環状線・各場所・ほかの建物からいちばん余裕のある所を毎回計算して決めます（場所や道を動かしても重ならない。いまの余裕は約19cmで、10cmを切るとブラウザのコンソールに警告が出るので、そのときは `HALL` を小さくする）。計算は外周から先に調べて早めに候補を落とすので、読み込みで約0.1秒です。

- **高架やデッキの下**: 足場の高さは、いま立っている高さで決まります（`groundAt(x, z, y)`）。駐車エリアのようなデッキは、その上にいる人と、一段（1.2m、`src/game.js` の `DECK_STEP`）以内の高さにいる人だけの足場で、それより下を歩いている人は下の地面を歩き続けます（高架の下で急にデッキの上へ飛ばされることはありません）。下の地面がデッキに近づいて頭がつかえるところ（デッキ面から `HEADROOM` 2.4m 以内）は、下からは入れません。ジャンプで乗れるのは踏み切った高さから二段（2.4m）以内のデッキだけで、デッキの下で跳ぶとデッキが天井になり、頭がその下で止まります（下から突き抜けて上に乗ることはありません）。地図からのワープは道の地面に降ります。保存される位置には高さも入るので、次に開いたときもデッキの上か下か、いた方に戻ります。
- **案内板**: 広場の井戸の横。エリア全体の地図（文字なし）で、調べると全体地図が開きます。
- **スマホ**: P か Tab（または右上のボタン）で取り出すゲーム内スマホ。MAP（全体地図）、MUSIC（見つけた曲の一覧。曲を選ぶとプレーヤーと購入ボタン、ストア・SoundCloud のリンク、その場所へワープする GO）、STORE（全曲のプレーヤーと購入ボタン）、LIVE（次のライブ）、SHOP（`SW.CONFIG.shop` のリンク）。
- **プレイヤー**: 「忘れられるように作る」服。どの年代にもどのシーンにも属さないほど普遍的で、外で暮らす人の服装のように機能だけが残ったもの。ロゴもアクセサリーもブランドもなく、顔も見せません：色落ちした黒のヘビーウェイトのオーバーサイズパーカー（落ちた肩、手がほとんど隠れる長い袖、腰まで覆う丈）をフードをかぶって着て、その下は目元だけ開いた黒いニットのフェイスカバー。裾からは長めの生成りのサーマルがのぞき、首には茶色の毛布のようなスカーフを二重に巻き、帆布のトートを長いストラップで斜めがけ。洗いざらしのチャコールのワイドパンツが、泥色のごついブーツの上にたまっています。
- **ライブ会場の観客**: 18人。ほかの街の人たちと同じ、普段着のバリエーション（下の「街の人たちの服」）で、一人ずつ違う組み合わせです。片手を突き上げる、両手を上げる、スマホで撮る、体を揺らす、の4種類の動きで、音が大きいほど大きく動き、強いキックで跳ねます。会場は三方の壁と2階の床で閉じていて外からは入口からしか見えないので、服の細部まで描くのはカメラが会場の中にいるか、入口の正面側で会場の中心から40m以内のときだけです。それより遠い正面側では同じ服の簡単な人影（まとめて1回の描画）が拍に合わせて弾み、110mより先や入口の見えない側では何も描きません。
- **街の人たちの服**: ライブ会場の観客、FIELD の通りの住人、FLIP の歩道の人混み、港町の商店街と遊歩道を歩く人は、部位ごとのバリエーションを別々に組み合わせて着ています（`src/game.js` の `npc`）。頭（肌の色、髪：短髪・坊主・ロング・お団子・アフロ・カール・ボブ・なし、髪の色）、頭のもの（なし・ニット帽・キャップ・後ろ向きキャップ・バケットハット・フードをかぶる・ヘッドホン・メガネ）、バッグ（なし・リュック・斜めがけのボディバッグ・トート・メッセンジャー・ショルダー）、トップス（長袖だけ：パーカー・スウェット・ロングコート・ダウン・カバーオール・ロンT・カーディガン・シャツ）、レイヤードのチラ見せ（裾・首元・袖口からのぞく下の服の色）、パンツ（ストレート・ワイド・スリム・ジョガー・カーゴ・ロングスカート）、足元（スニーカー・ランニング・ブーツ・ローファー・ハイカット）。形も色もそれぞれ別に選ぶので、同じ部品と素材でも組み合わせの数だけ違う人になります。歩道や商店街の人混みは、いくつかの服の組み合わせをインスタンス描画（組み合わせごとに1回の描画）で歩かせています。
- **山道（KEYAKI）**: 欅並木はなくなり、広場から北西のけやき山へ登る山道になりました。踏み固められた土の道が斜面に沿ってうねり（尾根の支脈を登り、肩で一息、山腹を横切って鞍部へ、つづら折りで山頂へ）、急なところは丸太の階段（段ごとに丸太が並び、両端を杭で留めてある）、片側が落ち込むところはロープの手すり、登り口・肩・つづら折りの角に道標（けやき展望台 ▶ / ◀ 広場）。肩には丸太のベンチの休憩所、道ばたには岩、斜面には森と若いけやき。山頂には木の展望デッキ（三方の手すり、海を向いたベンチ2つ、後ろから上がる階段）と「けやき山 展望台」の標柱、デッキの角には古い大きなけやきが立ち、葉が舞い落ち、木漏れ日の光の筋が差します。デッキの上の光の輪で「眺める」と、手すりの前から西の丘と OHH の浜、その向こうの海を見渡します（ほかの場所の「眺める」と違い、展望台なのでまわりの場所も消さずに映します。`p.lookout`）。道筋は `src/places.js` の `PLACES.keyaki` の `TW`（丘と同じワールド座標）で、道具はすべて丘ができてから（`p.afterHills`）地面の高さ（`groundAt`）に置かれます。
- **小道**: 踏み固められた土の小道が、広場から各場所まで続いています。広場のまわりには半径約30mの環状の小道があり、各場所への道を横につないでいます（広場に戻らずに隣の場所へ歩けます）。
- **光のつながり**: 各場所の空や光は、約115m手前から少しずつ混ざり始め、近づくと完全にその場所の色になります。昼の森から夜の街へ、線を越えた瞬間に切り替わることはありません。

| `src/places.js` / `src/places2.js` | 場所ごとの3Dジオラマ・景色のカメラ・音への反応 |
| `src/buildings.js` | ビルのデザイン6種類と、三角形など任意の凸形の敷地に建てる `plot()`（ガラスの高層・段々の塔・レンガのアパート・横長窓のオフィス・バルコニー付きの板状棟・低層＋塔）。高さに応じて無作為に選ばれ、FLIP・FIELD・SHOT・環状線の外の街並みで使用。各デザインに窓の色の組み合わせが3通り（暖色の住まい・白青のオフィス・ところどころ緑・青・紫・黄緑の部屋がある通り。ピンクと赤は使わない）あり、カーテン・ブラインド・人影も入る |
| `src/ring.js` | 環状線（中心線の計算と、路面・壁・橋脚・街灯・遠景のビル） |
| `src/cars.js` | 車のモデル7台 |
| `src/airport.js` | FIELD の通りの先の空港（ターミナル、旅客機、プライベートジェット、滑走路、管制塔） |
| `src/street.js` | 高架下の道（FLIP の北の枝から砂浜まで）と、砂浜沿いの車屋・ガレージ・中古車展示場 |
| `src/pass.js` | NO JOBB の南の山（高さの格子、高架のトンネルと坑口）と、車で走れる峠道（FLIP の南の枝から宮殿の裏まで、待避所3か所） |
| `src/game.js` | 描画（低解像度レンダリング＋ブルーム）、ワールド、アバター、ストリートウェアの部品（ドレッド・キャップ・シェード・チェーン・ダウン・ハイカット・迷彩とデニムの柄・宝飾用の映り込み。観客と共用で、骨ごとに同じ素材の部品を1つのインデックス付きメッシュにまとめて描画を軽くする）、操作、運転、近接オーディオ、店とスマホのプレーヤー・購入・購入の確認・再生回数 |
| `src/audio.js` | 場所ごとのオーディオチャンネル（距離で音量・こもり・定位、解析）、試聴の切り出し（ゲート）、店のプレーヤーの音と波形 |
| `src/synth.js` | 仮音源のシンセとパターン |
